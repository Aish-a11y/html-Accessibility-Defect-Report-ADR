# Severity Rubric (WCAG 2.2 AA)

| Severity | Definition | Examples |
|---|---|---|
| **Critical** | Blocks a core task entirely for a user group; no workaround. | Keyboard trap; form cannot be submitted without a mouse; content that triggers seizures (2.3.1). |
| **High** | Significantly degrades usability or violates a Level A criterion; workaround is difficult. | Missing alt text on informative images (1.1.1); no visible focus indicator (2.4.7); color as sole indicator (1.4.1). |
| **Medium** | Violates a Level AA criterion; usable but with friction. | Insufficient contrast (1.4.3); inconsistent navigation (3.2.3); target size below 24x24px (2.5.8). |
| **Low** | Minor deviation, best-practice gap, or Level AAA item; little to no functional impact. | Redundant alt text; non-descriptive link text where context clarifies it; minor heading structure issues. |

Severity = **conformance level** (A > AA > AAA) weighted by **how many users are blocked** and **whether a workaround exists**. When in doubt, rate by impact, not just criterion level.
