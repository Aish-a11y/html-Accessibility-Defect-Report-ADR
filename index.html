Accessibility Defect Report

Log accessibility issues found during testing and export them as a formatted Excel report.

Bulk import from a spreadsheet

Download the template and fill in a Page and Finding for each issue you found — that's all that's required. Leave WCAG SC, Change Type, User Impact and Recommendation blank and the built-in rules engine will suggest them from your finding text; fill them in yourself if you already know them. Occurrence defaults to "Desktop - Chrome/Edge" if left blank. Upload the completed file here and a formatted Excel defect report downloads automatically.

Accepted formats: .xlsx or .xls. Importing also downloads the finished Excel report.

Or log a single issue

Just describe the bug you found in plain language, then use "Suggest WCAG SC, priority & fix" — the WCAG criterion, user impact, change type and a recommended fix are auto-filled from a built-in rules library. Everything stays editable, so double-check the suggestion before adding the issue.
